# Car Price Data

This directory contains the datasets used by the car-price prediction project.

- `quikr_car.csv` — original scraped/raw vehicle records
- `quikr_car_cleaned.csv` — cleaned records prepared for analysis
- `Cleaned Data.csv` — cleaned export used by the notebook or application workflow

These files are inputs to the analysis in the parent directory. Preserve the original raw file and document any future cleaning changes in the notebook.
